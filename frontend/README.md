# BuildLog frontend

BuildLog의 React 화면입니다. 개발 중 `/api` 요청은 Vite가 `http://127.0.0.1:8000`의 FastAPI 서버로 전달합니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. 서버 상태를 확인하려면 FastAPI 서버도 함께 실행해야 합니다.

## 확인

```powershell
npm.cmd test
npm.cmd run build
```
